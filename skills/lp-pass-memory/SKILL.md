# Pass memory

Bessemer publishes an anti-portfolio so a pass is not forgotten and then repeated by accident. For LP IR the same habit is smaller: declined-by-us, passed, and blacklisted stay queryable, with the why.

This is not a public anti-portfolio. It is an internal check. Do not draft anything an LP would see.

## Hard rule

The reason is the status reason, blacklist reason, or a quoted note. If the status is Blacklisted or Declined by us and the reason field is empty, the output is **Do not re-open until someone writes the reason.** Do not invent a polite reason.

## Ask

The group or entity someone wants to put back on a list.

## Write

**Status now.** Active, Passed, Declined by us, or Blacklisted. Verbatim.

**Reason on file.** Paste it.

**Who decided, and when.** Only if a note or the blacklist-decided field says so.

**What changed since.** New commitment, new person, new note after that date. If nothing: nothing on file since the pass.

**Recommendation.** One of: leave it / partner should look / blocked. Blocked means blacklist or a reason that is a compliance or conduct issue. You do not clear a blacklist.
